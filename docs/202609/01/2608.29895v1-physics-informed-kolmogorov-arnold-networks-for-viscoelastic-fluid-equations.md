## 摘要
Kolmogorov-Arnold网络（KANs）受Kolmogorov-Arnold表示定理启发，通过在边上使用可学习的激活函数而不是固定的节点激活，提供了多层感知器（MLPs）的可解释替代方案。我们提出了一种物理信息Kolmogorov-Arnold网络（PI-KAN）框架，用于求解粘弹性流体方程的正问题，这些方程出现在许多复杂的流体动力学应用中，其特征在于流体场之间的强非线性耦合。对于粘弹性流体方程，我们采用广义流体动力学模型，该模型在尘埃等离子体领域已得到充分验证。为了评估所提出框架对粘弹性流体的性能，我们考虑基于Taylor-Green（TG）流和修正的Taylor-Green流的基准问题。我们系统地研究了不同网络架构、超参数和配点分布对PI-KANs在粘弹性参数（$τ_m = 1$--$20$）范围内的精度和收敛行为的影响。我们还研究了随机种子初始化对训练结果的影响。所得结果为设计和实现物理信息Kolmogorov-Arnold网络（PI-KANs）解决粘弹性流体方程提供了有用的指导。

## Abstract
Kolmogorov-Arnold Networks (KANs), inspired by the Kolmogorov Arnold representation theorem, provide an interpretable alternative to multilayer perceptrons (MLPs) by using learnable activation functions on edges rather than fixed node activations. We propose a Physics-Informed Kolmogorov-Arnold Network (PI-KAN) framework for solving forward problem of viscoelastic fluid equations, which arise in many complex fluid dynamics applications and are characterized by strong nonlinear coupling between fluid fields. For viscoelastic fluid equations, we adopt the generalized hydrodynamic model, which is well established in the field of dusty plasma. To evaluate the performance of the proposed framework for viscoelastic fluid, we consider benchmark problem based on the Taylor-Green (TG) flow and a modified Taylor-Green flow. We systematically investigate the effects of different network architectures, hyperparameters, and collocation point distributions on the accuracy and convergence behavior of PI-KANs for the range of viscoelastic parameter ($τ_m = 1$--$20$). We also study the impact of random seed initialization on training outcomes. The obtained results provide useful guidance for the design and implementation of physics-informed Kolmogorov-Arnold networks (PI-KANs) in solving viscoelastic fluid equations

## 2. 论文提出的方法论

### 2.1 核心思想
- 受 **Kolmogorov-Arnold 表示定理**启发，采用 KAN 作为神经网络主干，将传统 MLP 中节点上的固定激活函数替换为**边上的可学习激活函数**（B-spline 基函数组合）。
- 将广义流体动力学（GHD）方程作为物理约束嵌入损失函数，形成 **PI-KAN** 框架，实现物理一致性的求解。

### 2.2 网络结构
- 采用 **MultKAN** 架构，基本结构为：
  ```
  [2, 5, 5, 5, 5, 3]
  ```
  即输入层 2 个节点（x, y）、4 个隐藏层每层 5 个神经元、输出层 3 个节点（u, v, P 或 ω）。
- 后续针对高粘弹性参数（τm）增广网络宽度：
  - τm = 5 和 10 时扩展为 `[2, 7, 7, 7, 7, 3]`
  - τm = 20 时进一步扩宽为 `[2, 9, 9, 9, 9, 3]`
- 关键超参数：网格区间数 G = 3，B-spline 阶数 k = 3（三次样条）。

### 2.3 损失函数设计
总损失函数为各物理约束的加权和：

\[
L = \lambda_{div} L_{div} + \lambda_{MPDE} L_{MPDE} + \lambda_{BC} L_{BC} + \lambda_{\omega} L_{\omega}
\]

| 损失项 | 含义 |
|------|------|
| \(L_{div}\) | 连续性方程残差（不可压缩条件） |
| \(L_{MPDE}\) | 两个动量方程残差（结合粘弹性算子） |
| \(L_{BC}\) | 边界条件误差 |
| \(L_{\omega}\) | 涡量场辅助约束（物理正则化） |

> 由于 Taylor-Green 流和修正 Taylor-Green 流本身**不是**粘弹性方程（τm > 0）的精确解，因此动量残差的计算采用了**参考解析残差值** \(R'_{true}\) 和 \(R''_{true}\) 作为监督目标。

### 2.4 训练策略
- 优化器：两阶段训练
  1. **Adam 优化器**：300 步，学习率 η = 10⁻³，用于快速初始化；
  2. **L-BFGS 优化器**：20 次重启、每次 20 步，学习率 η = 1.0，用于精细收敛。
- **梯度裁剪**（max norm = 0.05）：抑制训练中的梯度爆炸，稳定损失曲面。
- **动态 PDE 权重策略**（continuation strategy）：
  - 对高 τm 情况，设置 \(\lambda_{MPDE} = 0.1\alpha\)，其中 α 在训练步 500–2500 之间从 0 线性增至 1；
  - 训练初期强调边界（λBC=100）和涡量（λω=20）约束，后期逐步加大 PDE 残差权重。
  - 对 τm=20 的极端情况，进一步降至 \(\lambda_{MPDE} = 0.02\alpha\)。
- 自动微分（automatic differentiation）用于计算输出对输入的导数，构造 PDE 残差。

采用广义流体动力学（Generalized Hydrodynamic, GHD）模型描述二维不可压缩粘弹性流体：

- 连续性方程：\(\partial_x u + \partial_y v = 0\)
- 动量方程（含粘弹性记忆算子）：

\[
\left[1 + \tau_m\left(\frac{\partial}{\partial t} + u\partial_x + v\partial_y\right)\right]
\left(\frac{\partial \mathbf{v}}{\partial t} + \mathbf{v}\cdot\nabla \mathbf{v} + \nabla P\right) = \nu \nabla^2 \mathbf{v}
\]

### 3.2 Benchmark 场景
1. **标准 Taylor-Green 涡流**（TG flow）：

2. **修正 Taylor-Green 流**（Modified TG flow）：

## 6. 论文的主要结论与发现

1. **PI-KAN 可有效求解粘弹性流体方程**：
   - 在低粘弹性（τm=1）下，PI-KAN 对标准 TG 流和修正 TG 流的预测与解析解高度吻合。
2. **高粘弹性带来显著挑战**：
   - 当 τm=5 且 β≤0.5 时，基础架构 `[2,5,5,5,5,3]` 出现明显偏差和对称性破坏，说明强记忆效应导致应力梯度更尖锐、多尺度特征更丰富。
3. **梯度裁剪是必要的稳定手段**：
   - 在 Adam 切换到 L-BFGS 时会出现损失尖峰，梯度裁剪（max norm=0.05）有效抑制了该不稳定现象。
4. **网络宽度与动态权重联合调优可扩展可解范围**：
   - 从 `[2,5,5,5,5,3]` 逐步扩展至 `[2,7,7,7,7,3]` 和 `[2,9,9,9,9,3]`，配合动态 PDE 权重递增策略，可准确求解 τm=10 和 τm=20 的强粘弹性流动。
5. **瓶颈架构在小参数设置下更优**：
   - U 形和 V 形架构在 τm=1 时取得最低 MSE（1.80×10⁻⁵ 和 2.16×10⁻⁵），优于直线均匀结构（3.64×10⁻⁵）。
   - 但考虑到高 τm 下需要足够容量，论文选择 Straight-Uniform 作为主配置，体现了“泛化鲁棒性优先于单点最优”的设计取舍。
6. **PI-KAN 比 MLP 更稳健**：
   - PI-KAN 的 MSE 下降更平缓、更稳定；MLP 虽在节点较多时接近 PI-KAN 性能，但捕捉复杂涡旋结构的能力不足。
7. **稀疏训练网格具有良好的空间泛化能力**：
   - 41×41 配点训练的模型在 256×256 和 512×512 测试网格上，训练/测试 MSE 曲线高度一致，说明模型学到的是连续场函数而非离散点记忆。
8. **PI-KAN 对随机初始化不敏感**：
   - 四个不同随机种子训练的模型（τm=20, β=0.25）在涡量场上视觉和数值上几乎不可区分，说明架构与训练策略有效消除了初始化偏差。

6. **良好的泛化验证**：测试网格远密于训练网格，验证了模型的连续泛化能力。

## 8. 不足与局限

1. **时间维度缺失**：
   - 所有实验仅取 t=0 的流场快照，粘弹性方程中的时间松弛项（\(\partial/\partial t\)）实际上未被动态求解。这是该方法在“求解粘弹性流体完整时空演化”方面的明显局限。
2. **压力场未充分展示与分析**：
   - 输出层包含 3 个节点（u, v 及压力或涡量），但结果部分主要展示速度与涡量场，压力场预测精度未做定量评估。
3. **与更先进方法的对比不足**：
   - 未与 Fourier Neural Operator（FNO）、DeepONet 等其他科学机器学习方法对比；
   - 未与传统高精度数值求解器对比精度和计算速度。
4. **混合参数 β 扫描较粗**：
   - 仅有 3 个 β 值，且在高 τm 时仅展示 β=0.25（最困难情形）的结果，对其余 β 配置的恢复情况缺乏精确量化。
5. **误差度量单一**：
   - 主要使用 MSE 评估，未提供相对 L2 误差、最大误差、涡量场分位数误差等更丰富的误差指标。
6. **计算资源未披露**：
   - 未给出 GPU 型号、训练时间、内存占用等，影响读者对方法可推广性的直接判断。
7. **η 与 λ 的设置经验性较强**：
   - 动态权重调度策略（α 的线性增加区间、λMPDE 的最优刻度）缺少更为系统的超参数搜索依据，可能对特定问题存在过拟合倾向。
8. **低 β 情形的物理含义有限**：
   - 修正 TG 流中相位偏移和频率叠加是人为构造的，虽有利于评估模型鲁棒性，但其与真实粘弹性流动（如 Oldroyd-B、FENE-P）的对应关系未被讨论。

这篇论文系统验证了 PI-KAN 作为粘弹性流体方程求解器的可行性，揭示了一系列影响精度与收敛的关键因素，并给出了从 τm=1 到 τm=20 的完整调优策略。其核心贡献在于：**将 KAN 的可解释性与物理信息学习的严谨性相结合，为强非线性、含记忆效应的流体系统提供了比传统 MLP-PINN 更加稳健和可靠的求解框架**。尽管在时间演化、更复杂本构模型和计算资源披露方面仍存在不足，但不失为 PI-KAN 应用于粘弹性流体问题的一项高质量基准性研究。
