## 摘要
物理信息神经网络（PINNs）将控制方程纳入神经网络训练，无需大型观测数据集即可近似PDE解。参数化PINNs（ParamPINNs）进一步将物理参数作为输入，使得单一模型能够表示参数域上一族PDE解。然而，现有的ParamPINNs仍然面临训练效率低下、不同参数下精度不均匀以及对有限采样参数任务过拟合的问题，这些问题会损害对未采样参数的泛化能力。为解决这些问题，我们提出了一种持续学习物理信息神经网络（CL-PINN），它将不同参数值下的PDE实例视为相关任务，并顺序学习这些任务。CL-PINN结合了基于贝叶斯优化的主动参数选择、按任务动态损失加权、稀疏物理约束回放以及可选的参数子网络，以在有界主动任务容量下改进任务分配和知识保留。它不需要观测数据，旨在有限计算资源下解决相对较宽参数域上的参数化PDE。在五个基准上的多随机种子评估（包括一个连续函数和四个参数化PDE）表明，与网格贪心搜索相比，贝叶斯选择显著减少了目标损失查询次数，同时稀疏回放缓解了对早期任务的遗忘。在规定的案例内资源协议下，CL-PINN通常比固定采样和网格贪心基线提供更高且更均衡的解精度。CL-PINN为学习跨物理参数泛化的PDE解提供了一条实用途径，并有望支持大规模工程参数研究中可复用的物理信息代理模型。

## Abstract
Physics-informed neural networks (PINNs) incorporate governing equations into neural-network training and can approximate PDE solutions without requiring large observational datasets. Parameterized PINNs (ParamPINNs) further take physical parameters as inputs, allowing a single model to represent a family of PDE solutions over a parameter domain. Existing ParamPINNs, however, still face inefficient training, uneven accuracy across parameters, and overfitting to a limited set of sampled parameter tasks, which can impair generalization to unsampled parameters. To address these issues, we propose a continual-learning physics-informed neural network (CL-PINN), which treats PDE instances at different parameter values as related tasks and learns them sequentially. CL-PINN combines Bayesian-optimization-based active parameter selection, task-wise dynamic loss weighting, sparse physics-constrained replay, and an optional parameter subnetwork to improve task allocation and knowledge retention under bounded active-task capacity. It requires no observational data and is designed to solve parameterized PDEs over relatively broad parameter domains under limited computational resources. Multi-seed evaluations on five benchmarks, including one continuous function and four parameterized PDEs, show that Bayesian selection substantially reduces objective-loss queries relative to grid-greedy search, while sparse replay mitigates forgetting of earlier tasks. Under the prescribed within-case resource protocols, CL-PINN generally provides higher and more balanced solution accuracy than fixed-sampling and grid-greedy baselines. CL-PINN offers a practical route toward learning PDE solutions that generalize across physical parameters and has the potential to support reusable physics-informed surrogates for large-scale engineering parameter studies.

## 2. 方法论

**核心思想：**

- 将不同参数值下的 PDE 实例视为**相关但分布不同的顺序任务**，借鉴持续学习（Continual Learning）中的“增量学习”思想，按顺序逐个学习这些参数任务，并通过主动采样、知识保留等手段提升整体泛化能力。

**关键技术组件：**

1. **贝叶斯优化主动参数选择（Bayesian-optimization-based active parameter selection）**
   - 在有限的“主动任务容量”（bounded active-task capacity）下，利用贝叶斯优化动态选择下一个要学习的参数值，而非均匀网格采样。
   - 优势：大幅减少目标损失（objective-loss）的查询次数，将有限计算预算集中在最“有价值”的参数区域。

2. **按任务动态损失加权（Task-wise dynamic loss weighting）**
   - 对不同参数任务自动分配不同的损失权重，在顺序学习过程中动态调整，平衡各任务的学习程度，缓解任务间的精度差距。

3. **稀疏物理约束重放（Sparse physics-constrained replay）**
   - 存储少量先前学习过的物理约束残差点，在训练新任务时回放（replay），缓解持续学习中经典的问题——**灾难性遗忘**，保留对早期任务的求解能力。

4. **参数子网络（Optional parameter subnetwork）**
   - 可选模块：为不同参数任务分配部分专属子网络参数，改善任务分配，减少任务间干扰。

**算法流程（文字描述）：**

- 初始化网络与参数池 → 在每次迭代轮次中，通过贝叶斯优化从候选参数集中选出一个最有益的参数任务 → 使用当前参数训练网络，同时以动态损失加权优化多个任务的联合损失 → 使用稀疏重放（从记忆缓冲区中抽取先前任务的物理约束点）防止遗忘 → 可选地使用参数子网络隔离任务专属知识 → 训练多个轮次直到满足精度或资源预算 → 最终得到一个可泛化到整个参数域的 PINN 模型。

## 3. 实验设计

**基准（Benchmarks）：**

- 共 5 个基准（benchmarks）用于评估：
  - 1 个**连续函数逼近**任务（简单验证场景）；
  - 4 个**参数化 PDE** 任务（实际核心场景），涵盖不同类型的偏微分方程（论文中为抽象描述，典型参数化 PDE 如扩散方程、对流方程等）。

**对比方法：**

- 固定采样（Fixed sampling）基线：均匀/固定网格采样参数训练；
- 网格贪心搜索（Grid-greedy）基线：按网格顺序贪心选择参数；
- 以 CL-PINN 作为完整方法进行对比。

**评估协议：**

- 多随机种子评估（multi-seed evaluations）以降低随机性偏差；
- 在规定的“案例内资源协议”（within-case resource protocols）下比较各方法，即各方法使用相近的计算预算。

## 6. 主要结论与发现

1. **贝叶斯选参显著提升效率**：相比网格贪心搜索，贝叶斯主动参数选择大幅减少了目标损失函数的查询次数，即在更少的采样下达到可比或更优的精度。
2. **稀疏重放有效缓解遗忘**：持续学习中经典的灾难性遗忘问题在 PINN 场景中也存在，而稀疏物理约束回放能够有效保留早期任务的解精度。
3. **精度更高且更均衡**：在规定的资源协议下，CL-PINN 相比固定采样和网格贪心基线，在整体精度和不同参数间的精度均衡性上均表现更好。
4. **无需观测数据**：方法完全基于物理约束，适用于无法获取真实观测数据的工程参数研究场景。

## 7. 优点

- **问题切入点新颖**：首次系统地将持续学习框架引入参数化 PINN 的任务顺序学习，针对“参数采样效率”和“灾难性遗忘”两个关键痛点进行解决。
- **方法组合具有实用价值**：贝叶斯主动选参 + 动态损失加权 + 稀疏重放 + 参数子网络，构成了一套在有限算力下提升参数化 PDE 求解泛化能力的系统工程方案。
- **无监督数据依赖**：不需要观测数据，仅依赖控制方程残差，保留了 PINN 的“物理驱动”本质。
- **面向应用**：以“可复用物理信息代理模型”为目标，具有很强的工程应用潜力（如地下水流模拟、多参数工程优化）。
- **实验验证较全面**：多基准、多种子、消融研究的设计，对方法效果提供了较好的证据支撑。

## 8. 不足与局限

- **算力信息缺失**：未公开 GPU 型号、数量与训练时长，影响可复现性和成本评估的透明度。
